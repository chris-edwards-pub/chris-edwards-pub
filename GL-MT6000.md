5. Save and Apply All Changes. SSIDs will probably be broken.
    1. After all the above steps, click the large "Save & Apply" button.
    2. The router will process the changes. You may lose network connectivity for a minute or two.
    3. Go back to Network > Wireless.
    4. You may see that the SSIDs you created for your VLANs are enabled but show an error of "wireless is not associated."
    5. This is where you will need to SSH to your router.
    6. run ssh root@192.168.8.1. Enter password.
    7. run vim /etc/config/wireless and find the interface associated with your VLAN SSIDs. Your SSID name will be under "option ssid".
    8. After the "option key" line insert option ifname 'raN' where N <= 3 for 2.4 GHz device or insert option ifname 'raxN' where N <= 3.

**IOT Interface (2.4 GHZ)**
```text
config wifi-iface 'wifinet4'
    option device 'mt798611'
    option mode 'ap'
    option encryption 'psk2'
    option key 'secret_key'
    option ifname 'ra2'
    option network 'IOT'
    option wmm '0'
    option macaddr 'DE:9F:27:0C:E7:EF'
    option ssid 'IOT'
```
